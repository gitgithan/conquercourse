## LinkedIn
- Link to use: `https://conquercourse.pages.dev/?ref=linkedin-launch`

> I built a ninja-warrior physics game where a real park, a real street or a photo of a bench becomes the course, and I made it for the Meta Global AI Developer Hackathon. The tagline is "Train slow. Run fast."
>
> The idea is that Meta's models turn the real world into pieces, but they never decide whether you cleared anything. SAM 3 cuts an object out of your photo, SAM 3D Objects lifts it into a 3D piece, and Muse Spark Open acts as a design partner that proposes a layout, yet a fixed 120 Hz simulator written in plain TypeScript is the only judge. Because the same keys always give the same result, your time is a fact, a friend can replay your run, and the server proves a clear by playing your keys again.
>
> The game is a side view on purpose: you look at the runner from the side, like a ninja-warrior course on television, because height and distance are what a jump depends on, and from the side you can see both at once. A real place is cut into one side-on lane for the same reason.
>
> One lesson I would share with any team: test on a second machine. We ran 7,525 runs on Node 22, Node 24 and Cloudflare's runtime, and every run had the same outcome, even though the last digit of some numbers differed. So we judge a run by what happened, and we use the exact digits only as an alarm for our own code changes.
>
> You can play it in your browser, build a course, and send a friend a short link to chase your ghost: https://conquercourse.pages.dev/?ref=linkedin-launch
>
