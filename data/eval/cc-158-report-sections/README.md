# CC-158: the end report, in sections

## So what
- The first thing a player sees on the end report is now "Share this run".
- "Download your clip" is the biggest and brightest button, "Copy challenge link" sits next to it.
- A friend who opens the link plays the same keys and tries to beat the time, so every report can start the next player.
- The rest is grouped: Play, Learn, More.
- Recommendation: keep it.
- Next step: watch what players press first on the live site.

## Layout
- Share card (dark, amber heading): Download your clip, Copy challenge link, name tag, one plain sentence.
- Play: Try again, next course, Chase the ghost (pinned at the bottom).
- Learn: Watch, Dojo (T).
- More: Close.
- On phones with the browser's share sheet, a "Share…" button appears after the clip is made.
