# Film C: character-led journey
- Version C of the Twitter demo film: calm "Train slow" half, then a fast "Run fast" half on a tempo drop.
- 69.6 s, 1280x720, 30 fps constant frame rate, H.264 with AAC, about 9.6 MB; a 15.3 s cut sits beside it.
- Videos are not in git; they live in the assets folder with a checksum file.
- Frames are captured by stepping the game clock (software GPU, about 4 s per 3D frame), never a live screen recording.
- Smoothness test: 160x90 frame differences; spikes are the planned page changes in the Dojo, Slicer and Editor clips.
- Still stretches in UI pages and in four flat run shots (band, climb, plank, recoil) count as duplicate frames.
- Music is the project's own map and course loops (100 and 140 bpm), cut on bar lines; no new music, no cost.
- Contact sheet: `contact-sheet.jpg` (18 frames across the film).
- Known gaps: the Slicer clip shows the real "cannot clear" panel while it builds; hero clips use the plain blocks style.
