# fork: bench lane or bulb lane (CC-133)

- Built and proved by `node scripts/demo-fork-course.mjs`; the answer and the reasons are in `docs/fork.md`.
- `run.json` holds the files used (bench, pole, bulbs ids), the course written, and both lanes' ideal runs: ticks, keys, room for error, and the lane each line is read as.
- No raw outputs: the run is a few seconds of search and is reproducible.
